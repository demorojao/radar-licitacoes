# web: site do Radar de Licitações

Site em Next.js 16 (App Router), TypeScript e Tailwind CSS.

A visão geral do projeto, como rodar e a documentação estão no [README principal](../README.md).

```bash
npm ci          # instala exatamente as versões do package-lock.json
npm run dev     # servidor de desenvolvimento em http://localhost:3000
npm run lint
npm run typecheck
npm run build
```
